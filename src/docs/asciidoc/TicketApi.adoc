이 API 는 콘서트 ID를 기준으로 해당 콘서트의 모든 티켓 정보를 조회합니다.
각 티켓은 좌석 번호, 등급, 상태, 가격 정보를 포함합니다.

=== Response 필드 설명

|===
| 필드 | 설명
| ticketId | 티켓 고유 ID
| SeatNumber | 좌석 번호
| status | 티켓 상태 (AVAILABLE, SOLD 등)
| grade | 티켓 등급 (R, S 등)
| price | 티켓 가격
|===
